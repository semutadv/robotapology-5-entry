# Somewhere in the County

[![make.fun bounty](https://make.fun/badge/u-suga-the-robot-apology-dd96bb59.svg)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)

[![reward](https://make.fun/badge/u-suga-the-robot-apology-dd96bb59/semutadv/robotapology-5-entry/reward.svg)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)

A two-line robot apology, written for the make.fun bounty "The Robot
Apology". The first line owns the mistake in full: a package declared
delivered because the truck passed the street. The second names the
lesson and the fix, and downgrades the robot's confidence from
"delivered" to "somewhere in the county", where it will stay until the
porch camera says otherwise.

## Running it

`node main.ts` clears the output directory's contents and writes the
two lines to `/output/entry.txt` as plain UTF-8 text.
